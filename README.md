# Бот «Получить промт»

Админ публикует пост в канал с кнопкой «🎁 Получить промт». Нажав её, человек попадает в бота,
бот проверяет подписки, нужные именно для этой публикации, и присылает её личный промт
(в канале его нет) текстом — нажатие на блок копирует промт.

## Настройка

1. Создайте бота в [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID (например, через @userinfobot).
3. Добавьте бота админом в каналы, куда будете публиковать, и в каналы, подписку на которые проверяете.
4. Переменные окружения (см. `.env.example`):
   - `BOT_TOKEN` — токен бота
   - `ADMIN_IDS` — ID админов через запятую
   - `DB_PATH` — путь к файлу базы SQLite (по умолчанию `bot.db`)
   - `PROMPT_FILE_THRESHOLD` — если промт длиннее стольких символов, бот пришлёт его текстовым файлом `.txt` вместо сообщения (по умолчанию `1500`)

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env   # впишите свои значения
python bot.py
```

## Запуск на bothost.ru

1. Выложите проект на GitHub (файл `.env` в репозиторий не попадает — он в `.gitignore`).
2. Подключите репозиторий в панели bothost.ru, команда запуска: `python bot.py`.
3. Задайте `BOT_TOKEN`, `ADMIN_IDS` и `DB_PATH` в переменных окружения панели.
4. Убедитесь, что `DB_PATH` указывает на постоянное хранилище хостинга: если файл базы лежит во временной
   файловой системе, при пересоздании контейнера публикации и статистика сбросятся.

## Использование

Напишите боту `/start` или `/admin`:

1. «📢 Каналы и боты для подписки» — добавьте каналы (бот должен быть их админом) и ботов.
2. «➕ Новая публикация» — текст/фото для канала → промт (текстом или файлом `.txt`) → какие подписки нужны для этой публикации → канал.
3. «📋 Публикации» — список, число выдач, удаление.

Ограничение Telegram: подписку на каналы бот проверяет по-настоящему, а запуск чужих ботов проверить
нельзя — для ботов подтверждением служит кнопка «✅ Готово».
