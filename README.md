# Бот «Получить промт»

Админ публикует пост в канал с кнопкой «🎁 Получить промт». Нажав её, человек попадает в бота,
бот проверяет подписки, нужные именно для этой публикации, и присылает её личный промт
(в канале его нет) текстом — нажатие на блок копирует промт.

## Настройка

1. Создайте бота в [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID (например, через @userinfobot).
3. Добавьте бота админом в каналы, куда будете публиковать, и в каналы, подписку на которые проверяете.
4. Переменные окружения (см. `.env.example`):
   - `BOT_TOKEN` — токен бота
   - `ADMIN_IDS` — ID админов через запятую
   - `DB_PATH` — путь к файлу базы SQLite (по умолчанию `bot.db`); либо `DATA_DIR` — папка, где будет лежать `bot.db`
   - `PROMPT_FILE_THRESHOLD` — если промт длиннее стольких символов, бот пришлёт его текстовым файлом `.txt` вместо сообщения (по умолчанию `1500`)

## Генерации: «Создать свой промт»

Пользователь в боте (постоянные кнопки внизу чата после /start или /menu; после каждого выданного промта из канала
бот присылает сообщение с кнопками «Создать свой промт» и «Поделиться»):
- **🎨 Создать свой промт** — присылает картинку-образец; бот показывает процент выполнения, анализирует её через OpenAI
  и присылает **промт текстовым файлом**. Этот промт отправляют в ChatGPT вместе со своим фото.
- **📤 Поделиться** — личная ссылка-приглашение. Новичкам — 1 бесплатная генерация; за 3 приглашённых друзей —
  ещё +1 (настраивается `REF_FRIENDS_NEEDED`, `REF_MAX_BONUSES`).
- **💳 Купить генерации** — 1 фото = 6 сомони, 3 = 14.99, 10 = 29.99 (цены — `PACKAGES` в `bot.py`).
  Бот показывает номер для оплаты (`PAY_PHONE`, `PAY_METHODS`), пользователь присылает чек, сообщение с реквизитами
  удаляется, пользователю пишется «платёж обрабатывается», а админам уходит фото чека с кнопками
  «✅ Подтвердить» / «❌ Отказ». После подтверждения генерации зачисляются автоматически.
- После промта на **платной** генерации есть кнопка **🎨 Сгенерировать моё фото**: пользователь присылает своё фото
  с хорошо видным лицом, бот (OpenAI) создаёт картинку по образцу с его лицом. На бесплатных генерациях кнопка
  предлагает купить пакет. Одна платная генерация — одно фото; при ошибке генерация не списывается.

Нужно в переменных окружения: `OPENAI_API_KEY`. Модели меняются в `OPENAI_VISION_MODEL` / `OPENAI_IMAGE_MODEL`
(у OpenAI они часто обновляются). Команды админа: `/aicheck` — проверка ключа и моделей,
`/give USER_ID N` — вручную начислить платные генерации. Процент выполнения — приблизительный (оценка по времени).

## Хранение базы в GitHub (чтобы данные не пропадали)

Можно использовать тот же репозиторий, что и для кода, даже публичный — база шифруется перед загрузкой
и лежит в отдельной ветке `data` (пуши в неё не перезапускают деплой из `main`).

1. GitHub → Settings → Developer settings → Personal access tokens → *Fine-grained tokens*:
   доступ только к этому репозиторию, право **Contents: Read and write**.
2. Переменные окружения:
   - `GITHUB_TOKEN` — токен
   - `GITHUB_REPO` — `username/repo`
   - `DB_ENCRYPT_KEY` — длинная случайная секретная фраза (**сохраните её**: без неё базу не расшифровать;
     в репозиторий и в код её не кладите)
   - `GITHUB_BRANCH` — ветка данных (по умолчанию `data`, создаётся сама)

При запуске, если локальной базы нет, бот скачивает и расшифровывает её; затем раз в 5 минут (`BACKUP_INTERVAL`)
сохраняет, если база изменилась, и при остановке. Вручную — команда `/backup`.
Если репозиторий публичный, а `DB_ENCRYPT_KEY` не задан, бот откажется загружать базу.

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env   # впишите свои значения
python bot.py
```

## Запуск на bothost.ru

1. Выложите проект на GitHub (файл `.env` в репозиторий не попадает — он в `.gitignore`).
2. Подключите репозиторий в панели bothost.ru, команда запуска: `python bot.py`.
3. Задайте `BOT_TOKEN`, `ADMIN_IDS` и `DB_PATH` в переменных окружения панели.
4. Убедитесь, что `DB_PATH` указывает на постоянное хранилище хостинга: если файл базы лежит во временной
   файловой системе, при пересоздании контейнера публикации и статистика сбросятся.

## Использование

Напишите боту `/start` или `/admin`:

1. «📢 Каналы и боты для подписки» — добавьте каналы (бот должен быть их админом) и ботов.
2. «➕ Новая публикация» — текст/фото для канала → промт (текстом или файлом `.txt`) → какие подписки нужны для этой публикации → канал.
3. «📋 Публикации» — список, число выдач, удаление.

Проверка подписок: подписку на каналы бот проверяет по-настоящему при каждом запросе промта.
Запуск ботов проверяется по-настоящему только для **ваших** ботов — при добавлении бота в каталог пришлите
его токен от @BotFather (сообщение с токеном бот сразу удаляет; токен можно добавить позже кнопкой «🔑 Токен»).
Для чужих ботов Telegram проверку не даёт — там подтверждением служит кнопка «✅ Готово».
Токены хранятся в базе, поэтому на публичном GitHub обязательно задайте `DB_ENCRYPT_KEY`.
